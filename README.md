<h3 align="center">About</h3>

<p align="center">
  I run <a href="https://crabsmp.net"><strong>CrabSMP</strong></a>, a Minecraft Bedrock server built on the
  Endstone plugin framework and backed by <strong>Crab Engine</strong>, a custom engine I write and maintain myself.<br/>
  The work runs the full depth of the stack, from gameplay systems and addon design down to
  VPS provisioning, proxy routing and TLS configuration.
</p>

<p align="center">
  I finished A levels with an <strong>A* in Computing</strong> and start a Computer Science degree this year.
</p>
