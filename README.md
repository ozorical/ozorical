<h3 align="center">About</h3>
<p align="center">
  I run <a href="https://crabsmp.net"><strong>CrabSMP</strong></a>, a Minecraft Bedrock server built on the
  Endstone plugin framework and backed by <strong>Crab Engine</strong>, a custom engine I write and maintain myself.<br/>
  That covers everything from gameplay systems and addon design down to VPS provisioning,
  proxy routing and TLS configuration.
</p>
<p align="center">
  I finished A levels with an <strong>A* in Computing</strong> and move on to a Computer Science degree this year.
</p>

<br/>

<h3 align="center">What I'm working on</h3>
<p align="center">
  <strong>Crab Engine</strong> &nbsp;·&nbsp; custom Bedrock server engine, currently focused on tick-loop profiling and CPU cost reduction<br/>
  <strong>Endstone plugins</strong> &nbsp;·&nbsp; gameplay commands, rank systems and generated in-game UI<br/>
  <strong>Infrastructure</strong> &nbsp;·&nbsp; Caddy with layer 4 routing, post-quantum TLS and Cloudflare DNS<br/>
  <strong>Data</strong> &nbsp;·&nbsp; player, economy and rank schemas across MongoDB and MySQL
</p>
